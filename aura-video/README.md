# Aura Video для Windows

Видео- и фотоплеер в стиле Aura Music. Версия 1.1.0.

**Скачать:** откройте файл [Aura-Video-Setup.exe](Aura-Video-Setup.exe) и нажмите «Download raw file» (значок скачивания справа).

После скачивания запустите установщик. Windows может показать синее окно «Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».

## Что нового в 1.1.0
- Все фото и видео открываются в одном окне, без новых окон на каждый файл.
- Прозрачная верхняя полоса с круглыми кнопками окна, как в Aura Music. Появляется при наведении курсора.
- Нижняя панель и стрелки по бокам появляются только при наведении курсора.
- Пробел в Проводнике открывает выделенное фото или видео, как Quick Look на Mac. Ещё раз пробел — окно закрывается.
- Удаление фото и видео в корзину (кнопка с корзиной или клавиша Delete).
- Esc закрывает плеер.
- Исправлены смещённые и обрезанные фото, снимки с телефона поворачиваются правильно.
- Плавное переключение между фото и видео, без рывков.
- Кнопка «Очистить» для списка недавних файлов.
