# Aura Video для Windows

Видео- и фотоплеер в стиле Aura Music.

**Скачать:** откройте файл [Aura-Video-Setup.exe](Aura-Video-Setup.exe) и нажмите «Download raw file» (значок скачивания справа).

После скачивания запустите установщик. Windows может показать синее окно «Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
