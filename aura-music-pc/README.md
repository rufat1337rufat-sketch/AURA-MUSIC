# Aura Music для Windows

Музыкальный плеер в дизайне Aura Music для компьютера. Версия 1.0.0.

**Скачать:** откройте файл [Aura-Music-Setup.exe](Aura-Music-Setup.exe) и нажмите «Download raw file» (значок скачивания справа).

После скачивания запустите установщик. Windows может показать синее окно «Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».

## Что умеет
- Ваша музыка с компьютера: «Добавить папку», «Добавить музыку», перетаскивание в окно, «Открыть с помощью» в Проводнике. Названия, исполнители, альбомы, обложки и длительность читаются из файлов.
- Вкладки как в Aura Music: Онлайн, Радио, Все, Избранное, Часто слушаемые, Плейлисты, а также Альбомы, Исполнители, Недавно добавленные.
- «Моя волна», подборки и поиск по каталогу (отрывки по 30 секунд), авто-радио по треку.
- Радио: русские, азербайджанские и английские станции, поиск, избранные станции.
- Обложки сами находятся для песен без обложки.
- Эффекты как в Aura Music: свечение, дыхание обложки, кольца на бит, светлячки, ветерок, глубина.
